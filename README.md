Simple Calculator using Tkinter
Overview

This is a simple and professional-looking calculator application built using Python's Tkinter library. It performs basic arithmetic operations such as addition, subtraction, multiplication, and division. The interface is clean, centered, and easy to use, featuring rounded buttons and a modern dark theme.

Features

User-friendly graphical interface

Rounded and colored buttons

Supports basic arithmetic operations (+, -, *, /, %)

Clear (AC) and Backspace functions

“0” button spans two columns for a realistic calculator layout

Centered and fixed-size window for consistent design

Error handling for invalid inputs

Requirements

Python 3.x

Tkinter (comes pre-installed with Python)

How to Run

Save the Python file (e.g., calculator.py) in your desired folder.

Open a terminal or command prompt in that folder.

Run the following command:

python calculator.py


The calculator window will appear in the center of your screen.
